# ProductInfoWarehouseStocks

<Badge type="tip" text="POST" /> `/v1/product/info/warehouse/stocks`

## Endpoint Overview

- **Category**：💰 Prices & Stocks
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v1/product/info/warehouse/stocks`

## Authentication Headers

| Parameter | Required | Description |
| :--- | :--- | :--- |
| `Client-Id` | Yes | Unique Client ID from seller cabinet |
| `Api-Key` | Yes | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "cursor": "",
  "limit": 10,
  "warehouse_id": 1020003080073000
}
```

## Responses

### HTTP 200 - Количество товара на складе FBS и rFBS

```json
{
  "stocks": [
    {
      "sku": 147035011,
      "product_id": 28743,
      "offer_id": "02105020-35",

      "updated_at": "2025-09-15T10:36:24.417498Z"
    }
```
