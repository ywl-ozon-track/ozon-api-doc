# SearchQueriesAPI SearchQueriesText

<Badge type="tip" text="POST" /> `/v1/search-queries/text`

## Endpoint Overview

- **Category**：💎 Premium Features & Chat
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v1/search-queries/text`

::: details View Official Description (Russian)
> Доступно для продавцов с подпиской [Premium Pro](https://seller-edu.ozon.ru/seller-rating/about-rating/podpiska-premium-pro).
> 
:::

## Parameters

| Parameter | In | Required | Description |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | No | Unique Client ID from seller cabinet |
| `Api-Key` | `header` | No | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "limit": "50",
  "offset": "0",
  "sort_by": "CLIENT_COUNT",
  "sort_dir": "ASC",
  "text": "string"
}
```
