# WarehouseFbsUpdatePickUpTimeslotList

<Badge type="tip" text="POST" /> `/v1/warehouse/fbs/update/pick-up/timeslot/list`

## Endpoint Overview

- **Category**：📌 FBSWarehouseSetup
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v1/warehouse/fbs/update/pick-up/timeslot/list`

## Parameters

| Parameter | In | Required | Description |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | No | Unique Client ID from seller cabinet |
| `Api-Key` | `header` | No | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "warehouse_id": 987654321
}
```

## Responses

### HTTP 200 - Список таймслотов

```json

  "timeslots": [

      "from": "00:00",
      "to": "00:00"

      "id": 1002,
      "from": "00:00",

    }
  ]
```
