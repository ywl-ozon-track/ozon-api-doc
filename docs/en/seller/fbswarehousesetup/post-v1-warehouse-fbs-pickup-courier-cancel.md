# WarehouseFbsPickUpCourierCancel

<Badge type="tip" text="POST" /> `/v1/warehouse/fbs/pickup/courier/cancel`

## Endpoint Overview

- **Category**：📌 FBSWarehouseSetup
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v1/warehouse/fbs/pickup/courier/cancel`

::: details View Official Description (Russian)
