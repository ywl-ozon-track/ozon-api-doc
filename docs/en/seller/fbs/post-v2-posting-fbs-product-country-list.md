# PostingAPI ListCountryProductFbsPostingV2

<Badge type="tip" text="POST" /> `/v2/posting/fbs/product/country/list`

## Endpoint Overview

- **Category**：📌 FBS
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v2/posting/fbs/product/country/list`

::: details View Official Description (Russian)
> Метод для получения списка доступных стран-изготовителей и их ISO кодов.
:::

## Authentication Headers

| Parameter | Required | Description |
| :--- | :--- | :--- |
| `Client-Id` | Yes | Unique Client ID from seller cabinet |
| `Api-Key` | Yes | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "name_search": "Алжир"
}
```

## Responses

### HTTP 200 - Список доступных стран-изготовителей

```json
{
  "result": [
    {
      "name": "Алжир",
      "country_iso_code": "DZ"
    }
  ]
}
```

### HTTP default - Ошибка

::: details View Schema Definition
```json
{
  "$ref": "#/components/schemas/googlerpcStatus"
}
```
:::
