# ProductStatusList

<Badge type="tip" text="POST" /> `/v1/product/certificate/product_status/list`

## Endpoint Overview

- **Category**：📜 Quality Certificates
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v1/product/certificate/product_status/list`

::: details View Official Description (Russian)
> Метод для получения списка возможных статусов товаров при их привязке к сертификату.
:::

## Parameters

| Parameter | In | Required | Description |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | No | Unique Client ID from seller cabinet |
| `Api-Key` | `header` | No | API Key generated in seller cabinet |

## Responses

### HTTP 200 - Список статусов товаров

```json
{
  "result": [
    {
      "code": "approved",
      "name": "Одобрен"
    },
    {
      "code": "declined",
      "name": "Отклонён"
    },
    {
      "code": "awaiting_verification",
      "name": "На проверке"
    }
  ]
}
```

### HTTP default - Ошибка

::: details View Schema Definition
```json
{
  "$ref": "#/components/schemas/rpcStatus"
}
```
:::
