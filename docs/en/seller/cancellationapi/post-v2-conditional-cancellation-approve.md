# CancellationAPI ConditionalCancellationApproveV2

<Badge type="tip" text="POST" /> `/v2/conditional-cancellation/approve`

## Endpoint Overview

- **Category**：📌 CancellationAPI
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v2/conditional-cancellation/approve`

::: details View Official Description (Russian)
> Метод позволяет согласовать заявку на отмену в статусе `ON_APPROVAL`. Заказ будет отменён, а деньги вернутся покупателю.
:::

## Authentication Headers

| Parameter | Required | Description |
| :--- | :--- | :--- |
| `Client-Id` | Yes | Unique Client ID from seller cabinet |
| `Api-Key` | Yes | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

## Responses

### HTTP 200 - Заявка подтверждена

### HTTP default - Ошибка
