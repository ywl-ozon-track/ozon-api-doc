# CargoesAPI CargoesDeleteStatus

<Badge type="tip" text="POST" /> `/v1/cargoes/delete/status`

## Endpoint Overview

- **Category**：📌 FboSupplyRequest
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v1/cargoes/delete/status`

::: details View Official Description (Russian)
> Метод для получения статуса удаления грузомест в заявке на поставку.
:::

## Authentication Headers

| Parameter | Required | Description |
| :--- | :--- | :--- |
| `Client-Id` | Yes | Unique Client ID from seller cabinet |
| `Api-Key` | Yes | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "operation_id": "test-operation-delete-12345-abcde"
}
```

## Responses

### HTTP 200 - Статус удаления грузоместа

```json
{
  "status": "SUCCESS",
  "errors": {
    "supply_error_reasons": [],
    "cargo_error_reasons": []
  }
}
```

### HTTP default - Ошибка

::: details View Schema Definition
```json
{
  "$ref": "#/components/schemas/googlerpcStatus"
}
```
