# pricing ids

<Badge type="tip" text="POST" /> `/v1/pricing-strategy/strategy-ids-by-product-ids`

## Endpoint Overview

- **Category**：🎯 Pricing Strategies & Buybox
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v1/pricing-strategy/strategy-ids-by-product-ids`

## Parameters

| Parameter | In | Required | Description |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | No | Unique Client ID from seller cabinet |
| `Api-Key` | `header` | No | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "product_id": [
    "29209"
  ]
}
```

## Responses

### HTTP 200 - Список идентификаторов

```json
{
  "result": {
    "products_info": [
      {
        "product_id": 29209,
        "strategy_id": "b7cd30e6-5667-424d-b105-fbec30a52477"
      }
    ]
  }
}
```
