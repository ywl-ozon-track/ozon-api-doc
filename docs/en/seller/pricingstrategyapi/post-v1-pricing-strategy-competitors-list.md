# pricing competitors

<Badge type="tip" text="POST" /> `/v1/pricing-strategy/competitors/list`

## Endpoint Overview

- **Category**：🎯 Pricing Strategies & Buybox
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v1/pricing-strategy/competitors/list`

::: details View Official Description (Russian)
> Метод для получения списка конкурентов — продавцов с похожими товарами в других интернет-магазинах и маркетплейсах.
:::

## Authentication Headers

| Parameter | Required | Description |
| :--- | :--- | :--- |
| `Client-Id` | Yes | Unique Client ID from seller cabinet |
| `Api-Key` | Yes | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "page": 1,
  "limit": 20
}
```

## Responses

### HTTP 200 - Список конкурентов

```json
{
  "competitor": [
    {
      "id": 7820251,
      "name": "grenmarketshop.ru"
    }
  ],
  "total": 33
}
```

### HTTP default - Ошибка

::: details View Schema Definition
```json
{
  "$ref": "#/components/schemas/rpcStatus"
}
```
:::
