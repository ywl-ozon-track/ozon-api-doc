# pricing items-add

<Badge type="tip" text="POST" /> `/v1/pricing-strategy/products/add`

## Endpoint Overview

- **Category**：🎯 Pricing Strategies & Buybox
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v1/pricing-strategy/products/add`

## Authentication Headers

| Parameter | Required | Description |
| :--- | :--- | :--- |
| `Client-Id` | Yes | Unique Client ID from seller cabinet |
| `Api-Key` | Yes | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "product_id": [
    "29209"
  ],
  "strategy_id": "e29114f0-177d-4160-8d06-2bc528470dda"
}
```

## Responses

### HTTP 200 - Ошибки при добавлении товаров

```json
{
  "result": {
    "failed_product_count": 0
  }
}
```

### HTTP default - Ошибка

::: details View Schema Definition
```json
{
  "$ref": "#/components/schemas/rpcStatus"
}
```
:::
