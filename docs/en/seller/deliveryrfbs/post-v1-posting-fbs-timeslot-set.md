# PostingAPI SetPostingTimeslot

<Badge type="tip" text="POST" /> `/v1/posting/fbs/timeslot/set`

## Endpoint Overview

- **Category**：📌 DeliveryrFBS
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v1/posting/fbs/timeslot/set`

::: details View Official Description (Russian)
> Вы можете изменить дату доставки отправления не больше двух раз.
> 
:::

## Parameters

| Parameter | In | Required | Description |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | No | Unique Client ID from seller cabinet |
| `Api-Key` | `header` | No | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "posting_number": "789456123-0002-3",
  "new_timeslot": {
    "from": "2026-03-16T14:00:00Z",
    "to": "2026-03-16T18:00:00Z"
  }
}
```
