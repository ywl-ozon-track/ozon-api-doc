# ReportAPI ReportReturnsCreate

<Badge type="tip" text="POST" /> `/v2/report/returns/create`

## Endpoint Overview

- **Category**：📌 ReportAPI
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v2/report/returns/create`

::: details View Official Description (Russian)
> Метод для получения отчёта о возвратах FBO и FBS.
:::

## Parameters

| Parameter | In | Required | Description |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | No | Unique Client ID from seller cabinet |
| `Api-Key` | `header` | No | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "filter": {
    "delivery_schema": "fbs",
    "date_from": "2024-09-16T00:00:00.000Z",
    "date_to": "2024-09-19T23:59:59.999Z",
    "status": "MovingToSeller"
  },
  "language": "DEFAULT"
}
```
