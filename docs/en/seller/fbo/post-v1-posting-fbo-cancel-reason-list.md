# PostingAPI GetPostingFboCancelReasonList

<Badge type="tip" text="POST" /> `/v1/posting/fbo/cancel-reason/list`

## Endpoint Overview

- **Category**：📌 FBO
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v1/posting/fbo/cancel-reason/list`

::: details View Official Description (Russian)
> Возвращает список причин отмены для всех FBO-отправлений.
:::

## Parameters

| Parameter | In | Required | Description |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | No | Unique Client ID from seller cabinet |
| `Api-Key` | `header` | No | API Key generated in seller cabinet |
