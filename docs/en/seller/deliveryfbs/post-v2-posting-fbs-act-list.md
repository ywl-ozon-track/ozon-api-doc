# PostingAPI FbsActList

<Badge type="tip" text="POST" /> `/v2/posting/fbs/act/list`

## Endpoint Overview

- **Category**：📌 DeliveryFBS
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v2/posting/fbs/act/list`

::: details View Official Description (Russian)
> Возвращает список актов по отгрузкам с возможностью отфильтровать отгрузки по периоду, статусу и типу интеграции.
:::

## Parameters

| Parameter | In | Required | Description |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | No | Unique Client ID from seller cabinet |
| `Api-Key` | `header` | No | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "filter": {
    "date_from": "2021-08-04",
    "date_to": "2022-08-04",
    "integration_type": "ozon",
    "status": [
      "delivered"
    ]
  },
  "limit": 50
}
```
