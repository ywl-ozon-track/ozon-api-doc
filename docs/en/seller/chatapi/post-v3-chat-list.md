# ChatAPI ChatListV3

<Badge type="tip" text="POST" /> `/v3/chat/list`

## Endpoint Overview

- **Category**：🗨️ Customer Support Chats
- **Method**：`POST`
- **Request URL**：`https://api-seller.ozon.ru/v3/chat/list`

::: details View Official Description (Russian)
> Возвращает информацию о чатах по указанным фильтрам.
:::

## Parameters

| Parameter | In | Required | Description |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | No | Unique Client ID from seller cabinet |
| `Api-Key` | `header` | No | API Key generated in seller cabinet |

## Request Body

Content-Type: `application/json`

```json
{
  "filter": {
    "chat_status": "OPENED",
    "unread_only": true
  },
  "limit": 1,
  "cursor": "304000402034"
}
```

## Code Examples

::: code-group
```bash [cURL]
curl -X POST "https://api-seller.ozon.ru/v3/chat/list" \
  -H "Client-Id: YOUR_CLIENT_ID" \
  -H "Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```

```python [Python]
import requests

url = "https://api-seller.ozon.ru/v3/chat/list"
headers = {
    "Client-Id": "YOUR_CLIENT_ID",
    "Api-Key": "YOUR_API_KEY",
    "Content-Type": "application/json"
}

response = requests.post(url, headers=headers, json={})
print(response.status_code, response.json())
```
