# Получить историю отгрузок курьерам

<Badge type="tip" text="POST" /> `/v1/warehouse/fbs/pickup/history/list`

## Обзор метода

- **Категория**：📌 FBSWarehouseSetup
- **HTTP-метод**：`POST`
- **URL запроса**：`https://api-seller.ozon.ru/v1/warehouse/fbs/pickup/history/list`
- **Описание**：

> [Подробнее об отгрузках курьеру в Базе знаний продавца](https://seller-edu.ozon.ru/fbs/ozon-logistika/otgruzka-kyruery)

## Параметры запроса

| Параметр | Расположение | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | Нет | Идентификатор клиента (Client ID) |
| `Api-Key` | `header` | Нет | API-ключ продавца (API Key) |
