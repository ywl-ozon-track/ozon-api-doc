# Установить скидку на уценённый товар

<Badge type="tip" text="POST" /> `/v1/product/update/discount`

## Обзор метода

- **Категория**：💰 Цены и остатки товаров
- **HTTP-метод**：`POST`
- **URL запроса**：`https://api-seller.ozon.ru/v1/product/update/discount`
- **Описание**：

> Метод для установки размера скидки на уценённые товары, продающиеся по схеме FBS.

## Параметры запроса

| Параметр | Расположение | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | Нет | Идентификатор клиента (Client ID) |
| `Api-Key` | `header` | Нет | API-ключ продавца (API Key) |

## Тело запроса

Content-Type: `application/json`

```json
{
  "discount": 10,
  "product_id": 876763232
}
```
