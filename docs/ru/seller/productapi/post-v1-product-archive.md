# Перенести товар в архив

<Badge type="tip" text="POST" /> `/v1/product/archive`

## 接口概览

- **所属模块**：📦 Загрузка и обновление товаров
- **请求方法**：`POST`
- **接口地址**：`https://api-seller.ozon.ru/v1/product/archive`
- **详细说明**：

> Возвращает статус запроса на архивацию.<br><br>Чтобы проверить фактическое состояние товара после архивации, используйте метод [/v3/product/info/list](#operation/ProductAPI_GetProductInfoList).<br>[Подробнее об управлении товарами в архиве в Базе знаний продавца](https://seller-edu.ozon.ru/libra/work-with-goods/zagruzka-tovarov/created-goods/upravlyat-tovarami-v-arhive)
> 


## 请求参数 (Parameters)

| 参数名 | 位置 (In) | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | 否 (No) | Ozon 卖家唯一 Client ID |
| `Api-Key` | `header` | 否 (No) | Ozon 开发者 API Key |

## 请求体 (Request Body)

Content-Type: `application/json`

```json
{
  "product_id": [
    "125529926",
    "987654321"
  ]
}
```

## 调用示例代码

::: code-group
```bash [cURL]
curl -X POST "https://api-seller.ozon.ru/v1/product/archive" \
  -H "Client-Id: YOUR_CLIENT_ID" \
  -H "Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```

```python [Python]
import requests

url = "https://api-seller.ozon.ru/v1/product/archive"
headers = {
    "Client-Id": "YOUR_CLIENT_ID",
    "Api-Key": "YOUR_API_KEY",
    "Content-Type": "application/json"
}

response = requests.post(url, headers=headers, json={})
print(response.status_code, response.json())
```
