# Отредактировать информацию о поставке на drop-off пункт

<Badge type="tip" text="POST" /> `/v1/fbp/order/drop-off/dlv/edit`

## Обзор метода

- **Категория**：🏬 Поставки FBP drop-off
- **HTTP-метод**：`POST`
- **URL запроса**：`https://api-seller.ozon.ru/v1/fbp/order/drop-off/dlv/edit`
- **Описание**：

> Вы можете оставить обратную связь по этому методу в комментариях к [обсуждению](https://dev.ozon.ru/community/1700-FBP-metody/) в сообществе разработчиков Ozon for dev.

## Параметры запроса

| Параметр | Расположение | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | Нет | Идентификатор клиента (Client ID) |
| `Api-Key` | `header` | Нет | API-ключ продавца (API Key) |

