# Информация о статусе редактирования товарного состава

<Badge type="tip" text="POST" /> `/v1/supply-order/content/update/status`

## Обзор метода

- **Категория**：📌 FboSupplyRequest
- **HTTP-метод**：`POST`
- **URL запроса**：`https://api-seller.ozon.ru/v1/supply-order/content/update/status`
- **Описание**：

> Метод для получения статуса редактирования товарного состава.
