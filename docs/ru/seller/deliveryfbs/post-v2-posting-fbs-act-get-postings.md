# Список отправлений в акте

<Badge type="tip" text="POST" /> `/v2/posting/fbs/act/get-postings`

## Обзор метода

- **Категория**：📌 DeliveryFBS
- **HTTP-метод**：`POST`
- **URL запроса**：`https://api-seller.ozon.ru/v2/posting/fbs/act/get-postings`
- **Описание**：

> Возвращает список отправлений в акте по его идентификатору.

## Параметры запроса

| Параметр | Расположение | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | Нет | Идентификатор клиента (Client ID) |
| `Api-Key` | `header` | Нет | API-ключ продавца (API Key) |

## Тело запроса

Content-Type: `application/json`

```json
{
  "id": 900000250859000
}
```
