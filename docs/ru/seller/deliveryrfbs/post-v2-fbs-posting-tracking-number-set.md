# Добавить трек-номера

<Badge type="tip" text="POST" /> `/v2/fbs/posting/tracking-number/set`

## Обзор метода

- **Категория**：📌 DeliveryrFBS
- **HTTP-метод**：`POST`
- **URL запроса**：`https://api-seller.ozon.ru/v2/fbs/posting/tracking-number/set`
- **Описание**：

> Добавить трек-номера к отправлениям. Вы можете передать до 20 трек-номеров за раз.

## Параметры запроса

| Параметр | Расположение | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | Нет | Идентификатор клиента (Client ID) |
| `Api-Key` | `header` | Нет | API-ключ продавца (API Key) |

## Тело запроса

Content-Type: `application/json`

```json
{
  "tracking_numbers": [
    {
      "posting_number": "48173252-0033-2",
      "tracking_number": "123123123"
    }
  ]
}
```
