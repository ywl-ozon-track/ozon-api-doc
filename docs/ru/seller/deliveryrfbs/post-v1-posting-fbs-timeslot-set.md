# Перенести дату доставки

<Badge type="tip" text="POST" /> `/v1/posting/fbs/timeslot/set`

## Обзор метода

- **Категория**：📌 DeliveryrFBS
- **HTTP-метод**：`POST`
- **URL запроса**：`https://api-seller.ozon.ru/v1/posting/fbs/timeslot/set`
- **Описание**：

> Вы можете изменить дату доставки отправления не больше двух раз.
> 

## Параметры запроса

| Параметр | Расположение | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | Нет | Идентификатор клиента (Client ID) |
| `Api-Key` | `header` | Нет | API-ключ продавца (API Key) |

## Тело запроса

Content-Type: `application/json`

```json
{
  "posting_number": "789456123-0002-3",
  "new_timeslot": {
    "from": "2026-03-16T14:00:00Z",
    "to": "2026-03-16T18:00:00Z"
  }
}
```
