# Отклонить заявку на скидку

<Badge type="tip" text="POST" /> `/v1/actions/discounts-task/decline`

## Обзор метода

- **Категория**：🎁 Акции Ozon
- **HTTP-метод**：`POST`
- **URL запроса**：`https://api-seller.ozon.ru/v1/actions/discounts-task/decline`
- **Описание**：

> Вы можете отклонить заявки в статусах: `NEW` — новые, `SEEN` — просмотренные.
> 

## Заголовки авторизации

| Параметр | Обязательный | Описание |
| :--- | :--- | :--- |
| `Client-Id` | Да | Идентификатор клиента (Client ID) |
| `Api-Key` | Да | API-ключ продавца (API Key) |

## Тело запроса

Content-Type: `application/json`

```json
{
  "tasks": [
    {
      "id": 78901,
      "seller_comment": "Ok"
    }
  ]
}
```

## Ответы сервера

### HTTP 200 - Заявки отклонены

```json
{
  "result": {
    "fail_details": [
      {
        "task_id": 78901,
        "error_for_user": "Скидка отклонена"
      }
    ],
    "success_count": 5,
    "fail_count": 1
  }
}
```

### HTTP default - Ошибка

::: details Посмотреть схему данных (Schema)
```json
{
  "$ref": "#/components/schemas/rpcStatus"
}
```
:::
