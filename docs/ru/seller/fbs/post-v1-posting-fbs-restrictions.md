# Получить ограничения пункта приёма

<Badge type="tip" text="POST" /> `/v1/posting/fbs/restrictions`

## Обзор метода

- **Категория**：📌 FBS
- **HTTP-метод**：`POST`
- **URL запроса**：`https://api-seller.ozon.ru/v1/posting/fbs/restrictions`
- **Описание**：

> Метод для получения габаритных, весовых и прочих ограничений пункта приёма по номеру отправления. Метод применим только для работы по схеме FBS.

## Параметры запроса

| Параметр | Расположение | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | Нет | Идентификатор клиента (Client ID) |
| `Api-Key` | `header` | Нет | API-ключ продавца (API Key) |

## Тело запроса

Content-Type: `application/json`

```json
{
  "posting_number": "76673629-0020-1"
}
```

## Ответы сервера

### HTTP 200 - Ограничения пункта приёма

```json
{
  "result": {
    "posting_number": "76673629-0020-1",
    "max_posting_weight": 40000,
    "min_posting_weight": 0,
    "width": 500,
    "height": 500,
    "length": 500,
    "max_posting_price": 500000,
    "min_posting_price": 0
  }
}
```
