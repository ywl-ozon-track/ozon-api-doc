# Список методов доставки realFBS-склада

<Badge type="tip" text="POST" /> `/v2/delivery-method/list`

## Обзор метода

- **Категория**：🏭 Работа со складами FBS и rFBS
- **HTTP-метод**：`POST`
- **URL запроса**：`https://api-seller.ozon.ru/v2/delivery-method/list`

## Параметры запроса

| Параметр | Расположение | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | Нет | Идентификатор клиента (Client ID) |
| `Api-Key` | `header` | Нет | API-ключ продавца (API Key) |

## Тело запроса

Content-Type: `application/json`

```json
{
  "cursor": "string",
  "filter": {
    "delivery_method_ids": [
      "string"
    ],
    "provider_ids": [
      "string"
    ],
    "status": [
      "NEW"
    ],
    "warehouse_ids": [
      "string"
    ]
  },
  "limit": 1,
  "sort_dir": "ASC"
}
```

## Примеры кода

::: code-group
```bash [cURL]

  -H "Client-Id: YOUR_CLIENT_ID" \
  -H "Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```

```python [Python]
import requests

url = "https://api-seller.ozon.ru/v2/delivery-method/list"
headers = {
    "Client-Id": "YOUR_CLIENT_ID",
    "Api-Key": "YOUR_API_KEY",
    "Content-Type": "application/json"
}

response = requests.post(url, headers=headers, json={})
print(response.status_code, response.json())
```
