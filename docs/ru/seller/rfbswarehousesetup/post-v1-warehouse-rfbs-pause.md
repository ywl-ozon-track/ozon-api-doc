# Поставить rFBS-склад на паузу

<Badge type="tip" text="POST" /> `/v1/warehouse/rfbs/pause`

## Обзор метода

- **Категория**：📌 rFBSWarehouseSetup
- **HTTP-метод**：`POST`
- **URL запроса**：`https://api-seller.ozon.ru/v1/warehouse/rfbs/pause`
- **Описание**：

> Скрывает товары склада с витрины. Изменять сток не нужно.

## Параметры запроса

| Параметр | Расположение | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | Нет | Идентификатор клиента (Client ID) |
| `Api-Key` | `header` | Нет | API-ключ продавца (API Key) |
