# Ozon 官方 API 同步与对账流水

本项目通过 GitHub Actions 定时机器人每日巡检 Ozon 官方 OpenAPI 规范，若检测到官方发布接口新增、参数调整或废弃，机器人会自动创建 Pull Request 并在此记录变更流水。

---

## 📅 2026-11-25 (仓库开源基线建立)
* **同步事件**: 仓库初始化并建立规范对账基线
* **Seller API 基线版本**: 官方 OpenAPI 3.0 (包含商品库、定价体系、FBS/FBO履约、仓库物流、退换货与财务账单全量接口)
* **Performance API 基线版本**: 官方 OpenAPI 3.0 (包含广告活动创建、关键词出价、推广转化与统计分析全量接口)
* **状态**: ✅ 已全量解析并通过 Redocly 渲染上架

---

## 🔍 对账与更新机制说明
1. **巡检周期**: 每天 UTC 02:00 (北京时间 10:00) 自动触发巡检；
2. **防篡改原则**: 机器人检测到任何变更后，**严禁直接 Push 到 main 分支**，必须生成结构化 Markdown 对比报告，并向管理员提交 PR；
3. **发布机制**: 只有管理员点击 Merge PR 后，GitHub Pages 才会自动重新打包构建发布。
