# Перенести дату доставки

<Badge type="tip" text="POST" /> `/v1/posting/fbs/timeslot/set`

## 接口概览

- **所属模块**：📌 DeliveryrFBS
- **请求方法**：`POST`
- **接口地址**：`https://api-seller.ozon.ru/v1/posting/fbs/timeslot/set`

::: details 查看官方详细说明 (Официальное описание)
> Вы можете изменить дату доставки отправления не больше двух раз.
> 
:::

## 请求参数

| 参数名 | 位置 (In) | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | 否 | 卖家后台唯一识别码 |
| `Api-Key` | `header` | 否 | 卖家后台生成的 API 访问令牌 |

## 请求体

Content-Type: `application/json`

```json
{
  "posting_number": "789456123-0002-3",
  "new_timeslot": {
    "from": "2026-03-16T14:00:00Z",
    "to": "2026-03-16T18:00:00Z"
  }
}
```

