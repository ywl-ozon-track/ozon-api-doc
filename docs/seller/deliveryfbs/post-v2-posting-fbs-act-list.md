# 获取актов по отгрузкам列表

<Badge type="tip" text="POST" /> `/v2/posting/fbs/act/list`

## 接口概览

- **所属模块**：📌 DeliveryFBS
- **请求方法**：`POST`
- **接口地址**：`https://api-seller.ozon.ru/v2/posting/fbs/act/list`
- **详细说明**：

> Возвращает список актов по отгрузкам с возможностью отфильтровать отгрузки по периоду, статусу и типу интеграции.


## 请求参数 (Parameters)

| 参数名 | 位置 (In) | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | 否 (No) | Ozon 卖家唯一 Client ID |
| `Api-Key` | `header` | 否 (No) | Ozon 开发者 API Key |

## 请求体 (Request Body)

Content-Type: `application/json`

```json
{
  "filter": {
    "date_from": "2021-08-04",
    "date_to": "2022-08-04",
    "integration_type": "ozon",
    "status": [
      "delivered"
    ]
  },
  "limit": 50
}
```
