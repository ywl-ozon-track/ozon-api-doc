# Поставить rFBS-склад на паузу

<Badge type="tip" text="POST" /> `/v1/warehouse/rfbs/pause`

## 接口概览

- **所属模块**：📌 rFBSWarehouseSetup
- **请求方法**：`POST`
- **接口地址**：`https://api-seller.ozon.ru/v1/warehouse/rfbs/pause`

::: details 查看官方详细说明 (Официальное описание)
> Скрывает товары склада с витрины. Изменять сток не нужно.
:::

## 请求参数

| 参数名 | 位置 (In) | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `Client-Id` | `header` | 否 | 卖家后台唯一识别码 |
| `Api-Key` | `header` | 否 | 卖家后台生成的 API 访问令牌 |
