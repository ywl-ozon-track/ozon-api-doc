# Снять rFBS-склад с паузы

<Badge type="tip" text="POST" /> `/v1/warehouse/rfbs/unpause`

## 接口概览

- **所属模块**：📌 rFBSWarehouseSetup
- **请求方法**：`POST`
- **接口地址**：`https://api-seller.ozon.ru/v1/warehouse/rfbs/unpause`

::: details 查看官方详细说明 (Официальное описание)
> Возвращает товары склада на витрину.
:::

| 参数名 | 位置 (In) | 必填 | 说明 |

| `Api-Key` | `header` | 否 | 卖家后台生成的 API 访问令牌 |
